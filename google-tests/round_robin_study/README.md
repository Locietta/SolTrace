# Round Robin Study Data

## Overview
This directory contains the soltrace input files (`soltrace_input_files`) and the resulting flux profiles and summaries for each phase of the round robin study (`results\phase_` + `I`, `II`, or `III`). For full field cases, the heliostat locations and aimpoint z-position adjustments can be found within `field_positions_aimpoints.csv`.

Details about the round robin study can be found within the Solar Energy Journal publication:

Mitchell, Rebecca, et. al. ``Modeling receiver flux of commercial power tower concentrating solar power plants using ray tracing: a round-robin comparison of SolTrace, Solstice, and TieSOL``, *Solar Energy*, vol. 300, 2025, https://doi.org/10.1016/j.solener.2025.113785.

Original database is available here: https://doi.org/10.5281/zenodo.15580027
